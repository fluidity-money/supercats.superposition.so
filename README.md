
# Supercats

previously Superposition Mainnet. The assets are deployed to a CDN at
https://cats-cdn.superposition.so.

The deployment on Robinhood Mainnet lives at `0xc4883d61f96bc661e313db85c01e3ce2625e5b7a`.
